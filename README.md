## Features

- Responsive layout, down to mobile
- Sticky nav with active-section highlighting on scroll
- Hero section with a photo frame
- Project cards for things I've built, with a placeholder slot for what's coming this semester
- Contact links (Email / GitHub / LinkedIn) — the email link opens Gmail's web compose directly instead of relying on a local mail client


## Project structure

```
portfolio/
├── index.html    → page structure & content
├── style.css     → all styling (colors, fonts, layout)
├── script.js     → interactivity (nav, scroll highlight, email link)
└── profile.jpg   → profile photo (not committed — add your own, see below)
```

## Adding your own photo

Drop an image named `profile.jpg` into the project root — it fills the hero photo frame automatically. If it's missing, the frame shows a placeholder instead of a broken image. If you're forking this, consider adding `profile.jpg` to `.gitignore` if you don't want your photo in a public repo.
